# Basic-Weather-App
A beginner-friendly Python weather application that fetches real-time weather data using the OpenWeatherMap API and displays temperature, humidity, weather conditions, and wind speed with error handling and location validation.

 Weather Application
A Python-based weather application that fetches **real-time weather data** using the **OpenWeatherMap API**. Users can search for a city or Indian ZIP code and view current weather conditions through a simple Tkinter GUI.

## Features

 City and ZIP code search
   Temperature in °C and °F
   Humidity
   Weather condition
   Wind speed
   Tkinter GUI
   API, network, and input error handling

Tech Stack
 Python
 Tkinter
 Requests
 OpenWeatherMap API

 Run
bash
pip install requests
python weather_app.py

Note: Add your OpenWeatherMap API key securely before running the application.

Beginner Python Project
